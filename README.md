# 컵 섞기 야바위 게임 (Cup Shuffle Game)

링크 접속 즉시 즐길 수 있는 브라우저 기반 야바위 미니게임입니다. 레벨이 올라갈수록 컵의 개수와 섞는 속도가 빨라져 도전 정신을 자극합니다.

---

## 🚀 실행 방법 (비전문가를 위한 가이드)

이 프로그램을 실행하려면 컴퓨터에 **Node.js**(버전 20 이상)가 설치되어 있어야 합니다.

1. **프로젝트 폴더 열기**
   - 다운로드받은 프로젝트 압축을 풀고, 터미널(명령 프롬프트)을 열어 해당 폴더로 이동합니다.

2. **패키지 설치하기**
   - 터미널에 아래 명령어를 입력하고 엔터를 칩니다.
   ```bash
   npm install
   ```

3. **게임 개발 서버 실행하기**
   - 설치가 완료되면 아래 명령어를 입력합니다.
   ```bash
   npm run dev
   ```

4. **웹 브라우저로 접속하기**
   - 터미널에 나타나는 로컬 주소(예: `http://localhost:5173`)를 복사하여 인터넷 브라우저(Chrome, Safari, Edge 등) 주소창에 붙여넣고 접속합니다.

---

## 🧪 테스트 실행 방법

작성된 게임 로직과 점수 산정 규칙의 정상 작동 여부를 테스트하려면 다음 명령어를 입력하세요.

```bash
npm test
```
