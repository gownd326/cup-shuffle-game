# 컵 섞기 야바위 게임 🥤 (Cup Shuffle Game)

링크 접속 즉시 즐길 수 있는 브라우저 기반 야바위 미니게임입니다.
동일한 화이트/크림톤 컵 카드 아래 숨겨진 붉은 공(🔴)의 궤적을 눈으로 쫓아 맞추는 게임입니다.
레벨이 올라갈수록 컵의 개수와 섞는 속도가 빨라지며, 게임 오버 시 닉네임을 등록하여 전 세계 플레이어들과 실시간 **TOP 5 명예의 전당** 랭킹을 겨룰 수 있습니다.

---

## 🚀 실행 방법 (비전문가를 위한 가이드)

이 프로그램을 실행하려면 컴퓨터에 **Node.js**(버전 20 이상)가 설치되어 있어야 합니다.

1. **프로젝트 폴더 열기**
   - 다운로드받은 프로젝트 압축을 풀고 터미널(또는 명령 프롬프트)을 열어 해당 폴더로 이동합니다.

2. **패키지 설치하기**
   - 터미널에 아래 명령어를 입력하고 엔터를 칩니다.
   ```bash
   npm install
   ```

3. **환경 변수 설정 (선택 사항)**
   - 온라인 실시간 랭킹을 Supabase DB와 연동하려면 `.env.example` 파일을 복사하여 `.env` 파일을 만든 후 Supabase 정보를 입력합니다.
   ```bash
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-key
   ```
   *(환경 변수를 설정하지 않아도 브라우저 로컬 저장소를 통해 최고 점수 및 랭킹 기능이 정상 동작합니다!)*

4. **게임 개발 서버 실행하기**
   - 설치가 완료되면 아래 명령어를 입력합니다.
   ```bash
   npm run dev
   ```

5. **웹 브라우저로 접속하기**
   - 터미널에 나타나는 로컬 주소(예: `http://localhost:5173`)로 브라우저에 접속합니다.

---

## 🧪 테스트 실행 방법

작성된 연기 테스트, 컵 카드 단일 외관 검증, 궤적 애니메이션, 1회 저장 제한 및 리더보드 동작을 테스트하려면 다음 명령어를 입력하세요.

```bash
npm test
```
