## 1. 프로젝트 개요 (한눈에 보기)

### 1. 프로젝트 목적
- 컵 아래에 숨겨진 공을 찾는 전통적인 '야바위' 규칙을 웹 브라우저에서 즐길 수 있는 미니게임 제공.
- 레벨이 올라갈수록 컵의 개수와 섞는 속도가 빨라져 도전 정신을 자극.

### 2. 핵심 가치
- 별도의 로그인이나 설치 없이 링크 접속 즉시 플레이 가능 (Vite 기반 초고속 로딩).
- 브라우저 로컬 저장소(`localStorage`)를 활용한 최고 점수(Best Score) 기록 시스템.

### 3. 주요 제약 사항
- 서버 데이터베이스(DB) 없이 프론트엔드 단독(Client-side)으로 동작.
- 모바일 및 데스크톱 환경 모두 지원하는 반응형 웹 디자인.

## 2. 사용자와 사용 시나리오

### 1. 타겟 유저
- 가볍게 웹 브라우저로 두뇌 회전 및 반사신경 게임을 즐기고 싶은 모든 연령층.

### 2. 유저 시나리오
1. **게임 시작 전**: 메인 화면에서 '게임 시작' 버튼을 누른다. 이 때 이전 최고 점수가 화면에 표시되어 있다.
2. **게임 진행**: 
   - 레벨 1: 컵 3개, 느린 속도로 섞기. 공이 들어간 컵을 보여준 뒤 섞기 시작.
   - 섞기가 끝나면 유저는 컵 1개를 선택.
   - 맞추면 점수 획득 후 레벨 업, 틀리면 게임 오버.
3. **게임 종료**: 틀린 컵을 고르면 '게임 오버' 팝업과 함께 이번 게임의 최종 점수와 최고 점수 경신 여부가 표시된다. '다시 하기' 버튼으로 재시작 가능.

## 3. 기능 명세

### 1. 게임 진행 로직
- **상태 정의 (`gameState`)**
  - `IDLE`: 게임 시작 대기 중
  - `PREVIEW`: 시작 전 공이 들어있는 컵을 1초 동안 보여줌
  - `MIXING`: 컵들이 실제로 자리를 바꾸는 애니메이션(좌우/교차 이동)을 수행 중 (유저 클릭 방지)
  - `CHOOSING`: 유저가 컵을 선택할 수 있는 상태
  - `ROUND_CLEAR`: 정답을 맞춰 다음 레벨로 넘어가기 전 잠시 대기 (1초)
  - `GAME_OVER`: 오답을 선택하여 게임이 종료된 상태

### 2. 레벨 디자인 세부 규칙
- **레벨 1**: 컵 3개, 섞기 횟수 4회, 섞기 속도(이동 간격) 500ms
- **레벨 2**: 컵 3개, 섞기 횟수 6회, 섞기 속도 400ms
- **레벨 3**: 컵 4개, 섞기 횟수 7회, 섞기 속도 350ms
- **레벨 4**: 컵 4개, 섞기 횟수 9회, 섞기 속도 300ms
- **레벨 5 이상**: 컵 5개, 섞기 횟수 10회 이상, 섞기 속도 250ms로 고정

### 3. 애니메이션 동작 규칙 (`MIXING` 상태)
- **좌표 기반 이동**: 각 컵의 DOM 요소 위치(X축)를 기억하고, 무작위로 선택된 두 컵의 인덱스를 교환할 때 서로의 X축 좌표 값(`transform: translateX(...)`)을 계산하여 부드럽게 미끄러지듯 이동한다.
- **이동 타이밍**: CSS `transition: transform 300ms cubic-bezier(0.4, 0, 0.2, 1);` 속성을 적용하여 60fps의 자연스러운 위치 교환 애니메이션을 보장한다.
- **중복 방지 및 상태 동기화**: 애니메이션 진행 중에는 유저의 클릭 입력을 완전히 차단(`pointer-events: none`)하며, 애니메이션 트랜지션이 끝난 후 배열 데이터를 갱신한다.

### 4. 점수 산정 방식
- 라운드 클리어 시 획득 점수 = `(현재 레벨 × 100) + (잔여 컵 개수 × 50) + (난이도 보너스)`
- 게임 종료 시 `localStorage`의 `cup_game_best_score`와 비교하여 현재 점수가 더 높을 경우 갱신.

## 4. 화면과 주소(URL) 구성

### 1. 화면 구성
- **단일 페이지 앱 (SPA)** 구조로 `/` 경로 하나에서 상태에 따라 화면 요소가 변경됨.

### 2. UI 레이아웃 및 텍스트
- **상단 헤더**: 
  - 타이틀: `🥤 컵 섞기 야바위` (폰트 크기 `text-2xl font-bold text-white`)
  - 점수판: `현재 점수: {score}` | `최고 점수: {bestScore}` | `레벨: {level}`
- **중앙 플레이 영역**:
  - 안내 문구 (`statusText`): 상태에 따라 "공의 위치를 기억하세요!", "섞는 중...", "공이 숨겨진 컵을 선택하세요!", "정답입니다! 다음 레벨로...", "게임 오버!" 표시
  - 컵 그리드: 가로로 나열된 컵 컴포넌트 (`flex justify-center gap-4 my-8 relative h-32`)
  - 컵 이동 애니메이션: 각 `CupItem`은 `absolute` 포지셔닝과 `transform: translateX(px)`를 사용하여 교차 이동 시 부드러운 애니메이션 적용 (`transition-transform duration-300 ease-in-out`)
  - 컵 시각 디자인: 이모지(🥤) 또는 직관적인 SVG 컵 아이콘 사용, 뒤집힌 모양 구현
- **하단 액션 영역**:
  - `IDLE` / `GAME_OVER` 상태: `게임 시작` 또는 `다시 하기` 버튼 (`bg-orange-500 hover:bg-orange-600 text-white font-bold py-3 px-6 rounded-lg`)

## 5. 데이터 모델

### 1. 로컬 저장소 (LocalStorage)
- **키 명칭**: `cup_game_best_score`
- **데이터 타입**: `number`
- **읽기/쓰기 규칙**:
  - 앱 최초 진입 시 `localStorage.getItem('cup_game_best_score')`를 호출하여 숫자로 파싱 (없거나 NaN일 경우 `0` 반환).
  - 게임 오버 시 `score > bestScore`인 경우 `localStorage.setItem('cup_game_best_score', score.toString())` 실행.

## 10. 테스트 계획

### 1. 수용 기준 (Given / When / Then)
- **시나리오 1: 정상 게임 시작 및 미리보기**
  - **Given** 사용자가 메인 화면(`/`)에 접속해 있다.
  - **When** '게임 시작' 버튼을 클릭한다.
  - **Then** 게임 상태가 `PREVIEW`로 바뀌며 공이 들어있는 컵이 1초 동안 강조 표시된다.

- **시나리오 2: 컵 이동 애니메이션 및 선택**
  - **Given** `PREVIEW` 상태가 끝나고 `MIXING` 상태로 진입했다.
  - **When** 설정된 속도(예: 400ms 간격)에 따라 컵들이 CSS `transform`을 통해 서로 자리를 바꾸는 애니메이션이 실행된다.
  - **Then** 모든 섞기 횟수가 완료된 후 `CHOOSING` 상태가 되며 유저가 컵을 클릭할 수 있다.

- **시나리오 3: 정답 선택 및 레벨 업**
  - **Given** 컵 섞기가 끝나고 유저가 컵을 선택할 수 있는 `CHOOSING` 상태이다.
  - **When** 공이 숨겨진 올바른 컵을 클릭한다.
  - **Then** 점수가 합산되고 레벨이 1 증가하며 다음 라운드가 시작된다.

- **시나리오 4: 오답 선택 및 게임 오버, 최고 점수 갱신**
  - **Given** `CHOOSING` 상태이다.
  - **When** 공이 없는 틀린 컵을 클릭한다.
  - **Then** 게임 오버 모달이 팝업되고, 현재 점수가 기존 최고 점수보다 높다면 `localStorage`에 즉시 반영된다.
